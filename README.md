# Ariel Fink

![Profile Views](https://komarev.com/ghpvc/?username=finktech-dev&style=flat-square&color=grey)

19 y/o self-taught developer from Buenos Aires, Argentina. I build products from scratch — design, code, ship. No CS degree, no bootcamp. Documentation, trial and error, and knowing which tools to use and when.

I'm also studying Social Communication Sciences, which shapes how I think about technology: not just how to build it, but what it does to people, work, and knowledge. In a world of constant technological change, I think knowing things — really knowing them — becomes more valuable, not less.

I'm genuinely curious about how AI works and how it develops. What happens to human skill when machines can replicate it? Who's responsible for what these systems do? I don't have answers. But I find the questions worth sitting with.

## What I'm building

**NCM Pro** — Desktop app for Argentine customs brokers. Private repo, active development.  
[ncm-clasificador.vercel.app](https://ncm-clasificador.vercel.app/)

**mcp-verify** — Open-source security auditing tool for MCP servers. 60+ OWASP-aligned detection rules, schema-aware fuzzing, real-time threat detection, SOC2 / HIPAA / PCI DSS compliance mapping.  
[github.com/FinkTech/mcp-verify](https://github.com/FinkTech/mcp-verify)

**Websites and AI integrations for local businesses** — Actively working with businesses in my area on web presence and practical AI implementations tailored to their actual workflows.

También estudio Licenciatura en Ciencias de la Comunicación Social, lo que cambia cómo pienso la tecnología: no solo cómo construirla, sino qué le hace a las personas, al trabajo y al conocimiento. En un mundo de cambio tecnológico constante, creo que saber cosas, realmente saberlas, se vuelve más valioso, no menos.

Me interesa genuinamente cómo funciona la IA y cómo se desarrolla. ¿Qué pasa con las habilidades humanas cuando las máquinas pueden replicarlas? ¿Quién es responsable de lo que estos sistemas hacen? No tengo respuestas. Pero me parecen preguntas que vale la pena hacerse.
